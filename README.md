# Reversible Planning — Tower of Hanoi

A formal verification project for **reversible STRIPS planning**, using the 2-disk Tower of Hanoi as benchmark. The domain is encoded in PDDL, verified for reversibility, and solved using an action-language planner.

## Overview

The project implements a complete pipeline for designing and verifying a reversible planning domain:

1. **PDDL encoding** — lifted and grounded domain definitions, translated to ASP via `plasp` and verified with `eclingo`.
2. **Reversibility verification** — formal check using `qasp` (Quantified Answer Set Programming) at multiple plan horizons.
3. **Plan generation** — action-language encoding solved by `DLV`, with constructive reverse plans computed by `RevPlan`.

## Problem

Move 2 disks from `peg1` to `peg3` following the standard Hanoi rules. The domain is designed so that **every action is reversible** — no state is a dead end.

## File Structure

```
├── domain.pddl              # Lifted PDDL domain
├── grounded_domain.pddl     # Grounded PDDL domain (used in the pipeline)
├── problem.pddl             # Problem instance
├── instance.lp              # ASP instance generated by plasp
├── check.qasp               # Quantified encoding for reversibility check
├── hanoi.plan               # Action-language encoding for DLV
├── hanoi.dl                 # Domain constants for DLV
└── hanoi_conditions.xml     # Pre/post-conditions for RevPlan
```

## Tools

| Tool | Purpose |
|------|---------|
| [`plasp`](https://github.com/potassco/plasp) | PDDL → ASP translation |
| [`eclingo`](https://github.com/potassco/eclingo) | Epistemic ASP solver for consistency verification |
| [`qasp`](https://github.com/alviano/qasp) | Quantified ASP for reversibility verification |
| [`DLV`](https://www.dlvsystem.it) | Disjunctive logic programming planner |
| [`RevPlan`](https://github.com/) | Reverse plan computation |

## Quick Start

```bash
# Translate PDDL to ASP
plasp translate grounded_domain.pddl problem.pddl > instance.lp

# Verify reversibility (eclingo)
cat grounded_domain.lp sequential-horizon_uurev.lp | eclingo -

# Verify reversibility (qasp, horizon N=1)
python pddl-to-qasp-uurev.py grounded_domain.pddl 1 > check.qasp
java -jar qasp.jar check.qasp

# Generate plan (DLV, horizon 7)
DLV hanoi.plan hanoi.dl -FP -N=7

# Compute reverse plans (RevPlan, horizon 3)
java -cp ./plan-library-binary.jar planlibrary.ReverseDomain \
     -x hanoi.plan hanoi.dl hanoi_conditions.xml ../../DLV 3
```

## Results

- `eclingo` confirms the domain is **SAT** and reverse plans exist at horizon 1.
- `qasp` returns **SAT** at both horizon 1 and 3, formally verifying strong reversibility.
- `DLV` finds a valid 7-step plan from the initial state to the goal.
- `RevPlan` constructively computes reverse plans from the goal back to the initial state.
